## Drone workflow

1. In Drone lab upload two aligned, opaque PNG/JPG/WebP crops of the same area. Start below 8 megapixels, maximum 4096 pixels per side. Confirm alignment.
2. Export the SAM 3 job JSON. The file contains both images and dates. Imagery remains local until you upload it to Colab.
3. Run the notebook cells in order. Upload the job JSON in the upload cell.
4. SAM3 segments the concept `building` in overlapping tiles. Pixel masks are merged, compared across dates with an edge tolerance, and filtered into candidate connected regions.
5. Download result JSON and ZIP. The ZIP includes building masks, candidate masks, overlay PNG and a PDF report generated by the notebook. PDF generation is implemented but unverified until an actual run completes.
6. In Results import geodevelop_result.json. Review previews, parameters, input hashes, candidate-region counts and uncertainty. Add review notes; export the overlay, reviewed JSON or print a PDF.

Connected candidate regions are NOT individual building counts. They can merge several roofs or represent only part of a structure. No validation labels, calibrated confidence, construction dates, geographic footprints or square-metre areas are produced.

The included sample job is synthetic and labeled illustrative. It is for testing the handoff; it is not a real drone survey or model result. Use actual authorized imagery for a meaningful test.
