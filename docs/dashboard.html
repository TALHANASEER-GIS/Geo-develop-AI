Before the first run

  • Request access to Meta SAM 3 weights and review the model terms.
  • A compatible GPU runtime is required; free availability is not guaranteed.
  • Store your token only in Colab Secrets as HF_TOKEN.
  • Start with an aligned crop under 8 megapixels and 4096 pixels per side.

What the model produces

Building segmentation masks for both dates. Our comparison code flags candidate added or removed regions after suppressing small edge offsets.

These regions are not verified building counts. Review alignment, shadows, missed roofs and false detections. No automatic construction date or geographic area is inferred.
